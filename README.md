## Реализация видеосистемы на FPGA с обработкой кадров (OV7670 + SystemVerilog + HLS)

### Проект представляет собой систему захвата видео с камеры OV7670, потоковую обработку данных (фильтрация изображения) и вывод изображения в HDMI.

### Технический стек
* **Языки:** SystemVerilog, C++
* **САПР:** Vivado, Vitis, Vitis HLS
* **Аппаратная платформа:** ZYNQ MINI XC7Z020CLG400-2

### Архитектура программно-аппаратного комплекса

### Аппаратная часть (FPGA / Programmable Logic)
#### rtl_modules (SystemVerilog):
  1. **ov7670_camera:** Захват видеопотока с камеры ov7670 в формате YUV. Преобразование в формат RGB888 и передача видеопотока по AXI-STREAM на следующий модуль обработки.
  2. **GaussFilterSystemVerilog:** Модуль фильтра Гаусса с окном 3х3.
  3. **MyScreen:** Модуль, который выдаёт видеопоток типа "шахматная доска" по AXI-STREAM.     
#### hls_ip_blocks (C++ / Vitis HLS):
  1. **MedianFilter:** Модуль медианного фильтра с окном 3х3, с возможностью динамической настройки порога через AXILite.
  2. **StreamToStream:** Модуль принимает поток пикселей по AXI-STREAM и тут же передаёт их по AXI-STREAM.
  3. **GaussFilter_hls:** Модуль фильтра Гаусса 3х3. С постоянными коэффициентами {{1, 2, 1} {2, 4, 2} {1, 2, 1}}. Через интерфейс можно управлять яркостью изображения меняя значение brightness от 0 до 255.
  4. **ReadWriteDDR:** Учебный модуль. Пишем поток видео в память DDR, при этом обрабатываем поток и находим статистику: минимальное, максимальное значение пикселя в кадре и средний сигнал кадра. Статистику можно считывать по AXILite. Далее читаем из памяти DDR записанный видеопоток и выводим на экран. Память DDR организована по принципу "ping-pong", в одну область пишем кадр из другой читаем, ранее записанный. Потом две области памяти меняются местами. Модуль создан с применением прерываний, когда кадр записан происходит прерывание.
  5. **SimpleDDE:** Простой алгоритм DDE, где для разделения видеопотока используется фильтр Гаусса 3х3. С возможность устанавливать значение усиления деталей.   
      
### Программная часть (ARM Cortex-A9 / Processing System)
#### drivers (C++ / Vitis):
  1. **ov7670_camera:** Драйвер конфигурации камеры ov7670 по I2C.
  2. **MyScreen:** Драйвер конфигурации модуля MyScreen.
  3. **MedianFilter_hls:** Драйвер конфигурации модуля MedianFilter и методы управления данным модулем.
  4. **StreamToStream:** Драйвер конфигурации модуля StreamToStream. Старт, Стоп.
  5. **GaussFilter_hls:** Драйвер конфигурации модуля GaussFilter_hls и управлением яркостью выходного видеопотока.
  6. **ReadWriteDDR:** Драйвер конфигурации модуля ReadWriteDDR. Включает организацию метода смену адресов в DDR для чтения-записи по прерыванию. Создана функция чтения статистики и вывод её в консоль.
  7. **SimpleDDE:** Драйвер конфигурации модуля SimpleDDE.
#### platform:
  1. **GenericInterruptController:** Инициализация подсистемы аппаратных прерываний.
  2. **I2C:** Инициализация интерфейса I2C в Zynq.
  3. **UART:** Инициализация интерфейса UART в Zynq.
  4. **VideoDirectMemoryAccess:** Настройка и инициализация VDMA. Буфер в три кадра в DDR.
  5. **VideoMixer:** Модуль смешивает изображения с камеры ov7670 и с VideoTestPatternGenerator. На выходе фон с видеопоток с ov7670 с разрешение 1080p.
  6. **VideoTestPatternGenerator:** Создаём фон с разрешение 1080р, в VideoMixer смешиваем с видеопотоком от ov7670.
